A cute little penguin companion for Orca ADE.

## The joke

> Status: PENGUIN! 🐧
> 
> Oops, I mean PENDING... ⏳

In software development, **pending** means something is still waiting to be completed.

But what if your pending task turned into a **penguin** instead?

Meet a tiny penguin who waddles around, takes little steps, and keeps you company while you wait.

This is a playful pun on the words **pending** and **penguin**, not a conventional English expression.

The task may still be pending, but your penguin is already here! 🐧❤️

**Some things are worth waiting for.** ❤️

## Bundle

Import [penguin.codex-pet/](penguin.codex-pet/) using the [installation guide](../../docs/INSTALLATION.md).

| Property | Value |
| --- | --- |
| Pet ID | `penguin` |
| Display name | Penguin |
| Manifest | [pet.json](penguin.codex-pet/pet.json) |
| Sprite atlas | [spritesheet.webp](penguin.codex-pet/spritesheet.webp) |
| Frame size | 192 × 208 pixels |
| Default animation | `idle` |

The manifest defines nine animation states: `idle`, `running-right`, `running-left`, `jumping`, `waiting`, `running`, `review`, `waving`, and `failed`, with explicit frame durations. Keep the manifest and sprite atlas together inside the bundle directory.
